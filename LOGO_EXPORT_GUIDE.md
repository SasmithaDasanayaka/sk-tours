# SK Tours Logo Export Guide

## Available Logo File

Your logo has been exported as: **`public/logo.svg`**

## How to Use for Different Platforms

### 📱 WhatsApp Business
**Requirements:** Square image, 640x640px PNG recommended

**Steps to convert:**
1. Open `public/logo.svg` in a browser
2. Use an online converter like:
   - CloudConvert (https://cloudconvert.com/svg-to-png)
   - Convertio (https://convertio.co/svg-png/)
3. Set dimensions to **640x640 pixels**
4. Download and upload to WhatsApp Business

**Alternative (using macOS Preview):**
1. Open `logo.svg` with Preview app
2. File → Export → Format: PNG
3. Set Resolution to 640x640
4. Save and upload

### 📘 Facebook Page
**Requirements:** Square image, minimum 180x180px (displayed at 170x170px)

**Steps:**
1. Use the same conversion method as WhatsApp Business
2. Set dimensions to **512x512 pixels** or higher
3. Upload to your Facebook page as profile picture

### 🎨 Quick Online Conversion

**Recommended tool:** https://svgtopng.com/
- Upload `public/logo.svg`
- Select size: 512px or 640px
- Download PNG
- Upload to your platforms
