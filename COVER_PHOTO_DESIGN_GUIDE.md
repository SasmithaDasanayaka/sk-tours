## 📝 Step-by-Step Canva Guide

### For Facebook Cover (820 x 312px):

1. **Open Canva** → "Create a design" → "Facebook Cover"
2. **Choose background**:
   - Upload your hero images from URLs above
   - OR use Canva's "Travel" templates
   - Apply gradient overlay (dark at 40% opacity)
3. **Add text layers**:
   - "SK THAI TOURS" (Montserrat Bold/Poppins Bold, 72px, white)
   - "Your Gateway to Thailand Adventures" (Montserrat Medium, 36px)
   - Add icon row: 🏙️ Bangkok | 🏖️ Pattaya | 🌊 Phuket
   - Bottom features: 📞 24/7 • ✨ Best Prices • 🎯 Custom Packages
4. **Add elements**:
   - Decorative lines or dividers
   - Optional: Thai pattern elements (search "Thai pattern" in Canva)
5. **Download**: PNG or JPG (high quality)

### For WhatsApp Profile (500 x 500px):

1. **Open Canva** → "Create a design" → Custom (500 x 500px)
2. **Choose background**:
   - Use a single striking Thailand image (Golden Temple, Beach, etc.)
   - OR solid gradient (teal to blue)
3. **Add logo text**:
   - Circle shape as background (semi-transparent dark, 80% size)
   - "SK" on top line (Bold, 60px)
   - "TOURS" below (Bold, 60px)
   - Icons: 🌴 ✈️ 🏖️ at bottom
4. **Ensure visibility**: Text must be readable even when small (96x96px preview)
5. **Download**: PNG (transparent background if needed)

## 🎯 Design Best Practices

### DO:
✅ Use high-quality images (minimum 1200px width)
✅ Add subtle dark overlay to images for text readability
✅ Keep text centered and easy to read
✅ Use consistent brand colors (blues, teals, golds)
✅ Include your key differentiators (24/7, Best Prices)
✅ Test how it looks at small sizes (mobile view)
✅ Include destinations: Bangkok, Pattaya, Phuket

### DON'T:
❌ Overcrowd with too much text
❌ Use low-resolution images
❌ Put important text near edges (Facebook crops on mobile)
❌ Use more than 3 fonts
❌ Make text too small (minimum 18px for readability)
❌ Ignore mobile preview
